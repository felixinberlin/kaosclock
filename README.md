# Chaos Clock

A Google Calendar add-on that rolls a focus mode + duration from your state and intent, creates the event, and occasionally rearranges your calendar according to vibes.

Chaos magick, minus the incense.

## What it does

- **Roll**: intent + energy + focus + time + chaos factor → mode, duration, sigil
- **Event**: creates a calendar event titled `[Gnosis] Finish landing page copy`
- **Log**: after the session, rate flow and save
- **Chaos events**: time drift, phantom slots, resurface, wandering events, reluctant servitor
